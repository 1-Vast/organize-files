# 内容判断与证据纠错

整理须同时判断“放在哪里”和“是否可信、能否使用”。阅读范围内报告时，主动检查影响结论、实验身份和后续执行的内容；仅以文件完整或链接有效，不能认定报告正确。普通资料也适用：版本、金额、日期、单位和任务状态均可能需要核对。

## 1. 发现问题并确定优先级

优先处理影响当前结论、采用版本、清理决定和后续任务的异常，再处理其余已发现错误。不是每条陈述都需联网或重算，但关键结论必须能定位依据；不能以“用户只说整理”忽略明显矛盾。

| 信号 | 需要查什么 | 可能的正确处理 |
|---|---|---|
| 报告与表格数值不一致 | 运行身份、原始行、单位、公式和汇总集合 | 确认口径后纠正抄录或计算；口径不同则分别保留 |
| 多种子均值接近最佳单次、重复数异常 | 纳入／排除清单、训练与读出关系、重复行 | 按已确认协议重算，不把失败记零或擅自去重 |
| “最新／最终”文件结果更好 | 数据版本、样本掩码、阶段、选择依据 | 同协议才判取代；不可比结果各归其位 |
| “显著、因果、普遍有效”缺少证据 | 实际检验、对照、样本独立性与覆盖范围 | 限定到可支持的观察；缺检验不等于证明无差异 |
| 解释与执行记录不一致 | 运行完成状态、错误日志及预期产物 | 区分方法负结果、工程失败和待验证假说 |
| “已同步／可复现”但文件缺失 | 本地实物、远端留存、校验对象与恢复入口 | 修正当前可用状态；不凭本地缺失宣称远端也丢失 |
| 引文、参数说明或 API 行为可疑 | 对应版本的原论文、官方文档、代码或配置 | 检查来源正文及适用条件，不以搜索摘要定论 |
| 重复报告相互引用同一结论 | 首次来源和实际实验记录 | 识别循环引用；多份副本不算独立佐证 |

低分、极端值或和常识不符只触发调查，本身不能证明错误。正确的反例和独有历史经验保留，不为了更好看的总结改数据。

## 2. 追查证据并核对适用范围

1. 从争议陈述反查原始资料：现行报告引用 → 运行清单、配置、输出及日志 → 生成脚本与依赖。先确认是同一数据、协议、版本和计算对象，再比较数值。所谓“原始 CSV”也可能损坏、缺行或属于另一个运行，不天然优于所有来源。
2. 优先用已有本地材料核验；涉及公开事实、方法定义或版本行为时，定向查原论文、官方资料、版本记录等一手来源，并读取支持该陈述的具体段落、图表或代码。公开检索不包含私人原始数据、日志和凭据。外部通用结论不能代替本次实验的缺失证据。
3. 必要时进行不改原始输入的低成本复算，如数值汇总、单位换算、样本计数、已有预测的指标复核。先核对有效样本、分组、缺失值、误差定义和排除规则；不能为了匹配报告调整这些规则。
4. 现有脚本也需核对输入、版本和实际逻辑。可用独立简单计算检验聚合，不要只重跑同一可疑脚本。若发现实现缺陷，保留受影响结果并标明；整理不自动授权修改模型、调参、安装依赖或重训。
5. 证据足够即修正；缺失输入、无法访问来源或仍有相互冲突证据时停止该项推断，记录查过什么、缺什么、对当前用途有什么影响及最小核验动作。继续不依赖该问题的整理，不展开无边界文献调研。

## 3. 按证据作出决定

| 判断结果 | 行动 |
|---|---|
| 确认错误，修正值／表述有依据 | 修正授权范围内的当前报告，并复核相关表格、导航和接续任务 |
| 看似矛盾，实为不同口径 | 补清协议、单位或身份，分开呈现；不强行统一 |
| 原说法超出已有证据 | 将当前总结限定到能支持的观察；原说法及缺证依据仍可追溯 |
| 只有可疑迹象，无法判定 | 标记“待核验”，保留双方来源，不选较新、较高或更有利的一方 |
| 未发现问题且证据充分 | 保持原内容，复用有效核验结果 |

默认整理包含对范围内普通可编辑工作报告（如 Markdown／文本报告）、维护汇总和索引的有据纠错，无需再次询问；仅审计则只报告发现。DOCX／PPTX／PDF 等交付稿的内容编辑按既有用户授权和文档场景规则处理。保护项、原始实验记录、冻结稿、签名文件及原始数据不直接改写。对保护文件中的错误，在可维护入口标注适用性并给具体修改建议，等待其各自编辑授权；不要在这些文件里静默“修正历史”。

纠错可以改变现行总结，但必须有可检查证据。改变科学假设、重新选择实验、提出新的机制结论或采用新模型，属于后续研究；不能借整理执行。若发现旧选择依据失效，明确该选择需要重审，不擅自指定新赢家。

## 4. 保留纠错关系而不制造报告堆积

在现有主题报告的对应位置简短保留：**原说法／来源 → 核验依据与方法 → 当前表述及限定**。关键证据指向文件、运行 ID、行／表或公开来源版本；复算所用输入、规则和最小可重做步骤有依据可查。根据内容采用一句注释或小表，不默认新增审计报告、原文件副本或完整重复日志。

例如，“旧报告将 R3 的 0.80 写为三种子均值；按清单 R1–R3 的 0.60、0.70、0.80 重算，均值为 0.70；仅验证保存分数的汇总。”这里保留了旧错误及修正依据；不能改写三个原分数，也不能把汇总核验称为训练复现。

发现同一成因的错误后，定向扩查相关生成脚本与引用，不无依据扩展到全部研究。修正后检查所有获准维护的当前消费者：报告正文、结果表、图注、导航、配置说明和下一步验收条件。已冻结或无编辑授权的文件列明未同步项，避免部分修正后仍被旧数字引导。单个不确定点只阻止依赖该点的结论采用、合并或删除，不阻止无关整理。

## 5. 验收判断是否真正有效

另一个 agent 应能从当前报告定位更正依据、区分“已纠正／不同口径／待核验”、复做可用的低成本检查，并了解哪些旧说法不再适用。原始证据仍在，无法确认的分歧没有被丢弃，正确内容没有被无依据改动。只报告实际完成的核验范围，不宣称所有科学结论已获证明。
